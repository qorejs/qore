# Security Policy

If you discover a security issue in Qore, please do not open a public issue first.

Instead, contact the maintainer privately and include:

- A clear description of the issue
- The affected version
- Steps to reproduce
- Any proof of concept or suggested remediation

Please give us reasonable time to investigate and prepare a fix before public disclosure.

## Scope

Security reports are especially helpful for:

- Adapter request handling
- Streaming transport parsing
- Markdown or rendering safety in demos
- Dependency or supply-chain concerns
